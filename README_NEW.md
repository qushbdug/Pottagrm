# بوت يمن نت المحسن 🇾🇪

## نظام بوت تليجرام متطور لبيع كروت الشبكة مع ميزات متقدمة

### 🆕 الميزات الجديدة والمحسنة

#### 1. **هيكلة محسنة للكود**
- تقسيم الكود إلى وحدات منفصلة للصيانة السهلة
- استخدام نمط OOP للتنظيم الأفضل
- فصل المنطق عن واجهة المستخدم

#### 2. **نظام المحفظة الإلكترونية 💳**
- تحويلات آمنة بين المحافظ
- دفع للتجار والأماكن
- سجل شامل للمعاملات
- حدود آمنة للتحويلات

#### 3. **نظام التقييم ⭐**
- تقييم الخدمات من 1-5 نجوم
- إحصائيات مفصلة للتقييمات
- تقارير التقييم التفاعلية
- متابعة مستوى رضا العملاء

#### 4. **نظام الإشعارات المتقدم 🔔**
- إشعارات push فورية
- إشعارات جماعية للمديرين
- إشعارات للقنوات
- تسجيل وتتبع الإشعارات

#### 5. **التقارير المتطورة 📊**
- تقارير المبيعات والربحية
- تقارير نشاط المستخدمين
- التقارير المالية المفصلة
- تقارير شاملة للإدارة

#### 6. **تحسينات قاعدة البيانات 🗄️**
- استخدام Context Managers للأمان
- فهارس محسنة للأداء العالي
- معالجة محسنة للأخطاء
- نظام ترحيل تلقائي

#### 7. **الأمان المحسن 🔒**
- تشفير محسن للبيانات الحساسة
- تسجيل شامل للأنشطة
- معالجة آمنة للمعاملات المالية
- حماية من التلاعب

### 🛠️ التثبيت والإعداد

#### المتطلبات
```bash
pip install -r requirements.txt
```

#### ترحيل البوت القديم
```bash
# تشغيل سكريبت الترحيل
python migrate_bot.py
```

#### تشغيل البوت المحسن
```bash
# تشغيل البوت الجديد
python main_bot.py
```

### 📁 هيكل المشروع

```
bot/
├── __init__.py
├── config.py              # إعدادات البوت
├── database/
│   ├── __init__.py
│   ├── connection.py      # إدارة الاتصال بقاعدة البيانات
│   ├── migrations.py      # ترحيل قاعدة البيانات
│   └── models.py          # نماذج قاعدة البيانات
├── models/
│   ├── __init__.py
│   ├── user.py           # نموذج المستخدم
│   ├── transaction.py    # نموذج المعاملات
│   ├── wallet.py         # نموذج المحفظة
│   └── rating.py         # نموذج التقييم
├── services/
│   ├── __init__.py
│   ├── notification_service.py  # خدمة الإشعارات
│   └── report_service.py        # خدمة التقارير
├── handlers/
│   ├── __init__.py
│   └── [معالجات الأوامر]
└── utils/
    ├── __init__.py
    └── encryption.py     # أدوات التشفير
```

### ⚙️ الإعدادات

#### متغيرات البيئة
```bash
# إعدادات اختيارية
export DB_PATH="/path/to/database.db"
export ENCRYPTION_KEY_B64="your_encryption_key"
export CARD_COMMISSION_RATE="0.10"
export AGENT_COMMISSION_RATE="0.05"
```

### 🎯 الأوامر الجديدة

- `/wallet` - المحفظة الإلكترونية
- `/rating` - تقييم الخدمة
- `/notifications` - الإشعارات
- `/reports` - التقارير (للمديرين)

### 🔧 الصيانة والتطوير

#### إضافة ميزة جديدة
1. إنشاء النموذج في `models/`
2. إضافة الخدمة في `services/`
3. إنشاء المعالج في `handlers/`
4. تحديث قاعدة البيانات في `migrations.py`

#### تشغيل الاختبارات
```bash
python -m pytest tests/
```
