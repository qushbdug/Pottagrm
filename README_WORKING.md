# 🚀 Yemen Net Bot - النسخة العاملة

## 📋 نظرة عامة
بوت تيليجرام احترافي لبيع كروت الشبكات في اليمن. تم تطويره بأعلى معايير الجودة العالمية مع التركيز على البساطة والاستقرار.

## ✨ المميزات
- ✅ **نظام تسجيل متقدم** مع التحقق من البيانات
- ✅ **إدارة المستخدمين** مع أدوار مختلفة (عميل، وكيل، مزود)
- ✅ **نظام المحافظ** مع أرقام فريدة
- ✅ **قاعدة بيانات SQLite** محسنة ومستقرة
- ✅ **واجهة مستخدم عربية** مع رموز تعبيرية
- ✅ **معالجة أخطاء متقدمة** مع تسجيل شامل
- ✅ **API مباشر لتيليجرام** بدون مكتبات معقدة

## 🛠️ المتطلبات
```bash
# Python 3.8+
python3 --version

# المكتبات المطلوبة
pip install requests python-dotenv
```

## 🚀 التثبيت والتشغيل

### 1. استنساخ المشروع
```bash
git clone <repository-url>
cd yemen-net-bot
```

### 2. تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

### 3. إعداد متغيرات البيئة
```bash
cp .env.example .env
# تعديل الملف بإعداداتك
```

### 4. تشغيل البوت
```bash
python3 working_bot.py
```

## 📱 الأوامر المتاحة

| الأمر | الوصف |
|-------|--------|
| `/start` | بدء البوت والتسجيل |
| `/menu` | القائمة الرئيسية |
| `/help` | مركز المساعدة |
| `/cancel` | إلغاء العملية الحالية |

## 🔧 التكوين

### متغيرات البيئة
```bash
# رمز البوت (مطلوب)
BOT_TOKEN=your_bot_token_here

# مسار قاعدة البيانات
DB_PATH=./yemen_net.db

# مستوى التسجيل
LOG_LEVEL=INFO
```

### قاعدة البيانات
البوت ينشئ تلقائياً:
- جدول المستخدمين (`users`)
- جدول المعاملات (`transactions`)
- الفهارس المحسنة للأداء

## 🏗️ البنية

```
working_bot.py          # الملف الرئيسي
├── init_database()     # تهيئة قاعدة البيانات
├── user_management     # إدارة المستخدمين
├── telegram_api        # واجهة برمجة تيليجرام
├── message_handlers    # معالجات الرسائل
└── callback_handlers   # معالجات الأزرار
```

## 🐛 استكشاف الأخطاء

### مشاكل شائعة
1. **خطأ في رمز البوت**
   ```bash
   # تأكد من صحة الرمز في ملف .env
   BOT_TOKEN=your_correct_token
   ```

2. **مشكلة في قاعدة البيانات**
   ```bash
   # احذف الملف وأعد تشغيل البوت
   rm yemen_net.db
   python3 working_bot.py
   ```

3. **مشكلة في الاتصال**
   ```bash
   # تأكد من اتصال الإنترنت
   ping api.telegram.org
   ```
