# 🤖 بوت يمن نت المحسن

بوت تليجرام متطور ومحسن لبيع كروت الشبكة مع ميزات متقدمة ونظام محاسبي شامل.

## ✨ الميزات الجديدة

### 🔄 التحسينات الأساسية
- ✅ **إصلاح جميع مشاكل الاستيراد** - تم حل مشكلة `bot.database.models`
- ✅ **نظام ترحيل محسن** - يتعامل مع قواعد البيانات القديمة بأمان
- ✅ **هيكل محسن للبوت** - جميع الدوال المطلوبة متوفرة
- ✅ **معالجة أخطاء متقدمة** - مقاومة للأخطاء ومستقرة

### 💳 المحفظة الإلكترونية
- تحويل الأموال بين المستخدمين
- سجل معاملات مفصل
- حماية متقدمة بالتشفير
- إشعارات فورية للمعاملات

### ⭐ نظام التقييم
- تقييم الخدمات (1-5 نجوم)
- إحصائيات التقييم الشاملة
- تقارير مفصلة عن جودة الخدمة

### 📊 نظام التقارير
- تقارير المبيعات
- تقارير النشاط
- التقارير المالية
- تقارير التقييمات

### 🔔 نظام الإشعارات
- إشعارات فورية للمعاملات
- إشعارات الترحيب والتحديثات
- إدارة الإشعارات المقروءة/غير المقروءة

## 🚀 التشغيل السريع

### 1. التشغيل المحلي
```bash
# تثبيت المتطلبات
pip install -r requirements.txt

# تشغيل البوت
python start.py
```

### 2. النشر على Render
1. ارفع الكود إلى GitHub
2. اربط المستودع بـ Render
3. ملف `render.yaml` سيتولى الإعداد تلقائياً

### 3. ترحيل قاعدة البيانات
```bash
# تشغيل سكريبت الترحيل
python migrate_bot.py
```

## 📁 هيكل المشروع

```
bot/
├── config.py              # إعدادات البوت
├── database/              # إدارة قاعدة البيانات
│   ├── __init__.py
│   ├── connection.py      # إدارة الاتصال
│   └── migrations.py      # ترحيل قاعدة البيانات
├── models/                # نماذج البيانات
│   ├── __init__.py
│   ├── user.py           # نموذج المستخدم
│   ├── wallet.py         # نموذج المحفظة
│   ├── rating.py         # نموذج التقييم
│   └── transaction.py    # نموذج المعاملات
└── services/             # الخدمات المتقدمة
    ├── notification_service.py
    └── report_service.py

main_bot.py               # البوت الرئيسي المحسن
start.py                  # ملف بدء التشغيل
migrate_bot.py            # سكريبت الترحيل
render.yaml               # إعدادات Render
requirements.txt          # متطلبات Python
```

## ⚙️ الإعدادات

### متغيرات البيئة
```bash

DB_PATH=yemen_net.db
```

### إعدادات Render
- **Build Command**: `pip install -r requirements.txt`
- **Start Command**: `python start.py`
- **Environment**: Python 3.13+
