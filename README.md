# 🤖 Yemen Net Bot - بوت يمن نت

نظام بوت تليجرام متطور لبيع كروت الشبكة مع ميزات متقدمة وإدارة شاملة للمستخدمين والمبيعات.

## ✨ الميزات الرئيسية

- 🛒 **نظام مبيعات متكامل** - إدارة كروت الشبكة والمبيعات
- 👥 **إدارة المستخدمين** - نظام صلاحيات متقدم مع أدوار مختلفة
- 💰 **نظام محفظة إلكترونية** - إدارة الأرصدة والمدفوعات
- 📊 **تقارير وإحصائيات** - تتبع الأداء والمبيعات
- 🔔 **نظام إشعارات ذكي** - إشعارات مخصصة للمستخدمين
- ⭐ **نظام تقييم** - تقييم البائعين والخدمات
- 🗄️ **قاعدة بيانات محسنة** - نظام ترحيل تلقائي

## 🚀 التثبيت والتشغيل

### المتطلبات

- Python 3.8+
- قاعدة بيانات SQLite
- توكن بوت تليجرام

### التثبيت

1. **استنساخ المستودع**
```bash
git clone <repository-url>
cd yemen-net-bot
```

2. **تثبيت المتطلبات**
```bash
pip install -r requirements.txt
```

3. **إعداد متغيرات البيئة**
```bash
cp .env.example .env
# تعديل .env بإعداداتك
```

4. **تشغيل البوت**
```bash
# للتطوير المحلي
python run_bot.py

# للإنتاج (Render)
python main.py
```

## 🔧 الإعداد

### 1. إعداد بوت تليجرام

1. إنشاء بوت جديد عبر [@BotFather](https://t.me/BotFather)
2. الحصول على توكن البوت
3. إضافة التوكن في ملف `.env`

### 2. إعداد قاعدة البيانات

البوت يقوم بإنشاء قاعدة البيانات تلقائياً مع تشغيل الترحيلات.

### 3. إعداد Render (اختياري)

1. رفع الكود إلى GitHub
2. ربط المستودع بـ Render
3. إعداد متغيرات البيئة

## 📱 الأوامر المتاحة

- `/start` - بدء استخدام البوت
- `/menu` - القائمة الرئيسية
- `/balance` - عرض الرصيد
- `/wallet` - إدارة المحفظة
- `/stats` - الإحصائيات
- `/rating` - نظام التقييم
- `/notifications` - الإشعارات
- `/reports` - التقارير

## 🛠️ التطوير

### إضافة ميزات جديدة

1. إنشاء نموذج جديد في `bot/models/`
2. إضافة الخدمة في `bot/services/`
3. تحديث `main_bot.py` بإضافة المعالجات

### تشغيل الاختبارات

```bash
python -m pytest tests/
```
