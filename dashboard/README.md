# Yemen Net Bot Dashboard 🤖

لوحة تحكم ويب متكاملة لإدارة بوت كروت الإنترنت اليمني

## ✨ المميزات

### 🔐 نظام الأمان
- **تسجيل دخول آمن**: باستخدام معرف Telegram + OTP
- **صلاحيات محدودة**: للمشرف الأعلى فقط
- **جلسات مؤمنة**: باستخدام JWT tokens
- **تشفير البيانات**: جميع الاتصالات مؤمنة

### 📊 الصفحة الرئيسية
- إحصائيات سريعة (العملاء، المشرفين، المبيعات، الأرصدة)
- رسوم بيانية تفاعلية للمبيعات
- آخر المعاملات المالية
- مؤشرات الأداء الرئيسية

### 👥 إدارة العملاء
- عرض جميع العملاء مع البحث والفلترة
- تعديل بيانات العملاء
- إدارة أرصدة العملاء
- تفعيل/إيقاف الحسابات
- عرض تاريخ المعاملات لكل عميل

### 🛡️ إدارة المشرفين
- إضافة مشرفين جدد
- تعديل صلاحيات المشرفين
- إدارة أدوار النظام
- سجل نشاطات المشرفين

### 💸 طلبات السحب
- عرض جميع طلبات السحب
- تغيير حالة الطلبات (قيد المراجعة/مقبولة/مرفوضة)
- إضافة ملاحظات إدارية
- إشعارات تلقائية للعملاء

### 📢 الرسائل الجماعية
- إرسال رسائل لجميع العملاء
- استهداف مجموعات محددة
- معاينة الرسائل قبل الإرسال
- تتبع حالة التسليم

### 📈 النظام المحاسبي
- تقارير مالية شاملة
- إحصائيات المبيعات اليومية/الشهرية
- تحليل الأرباح والخسائر
- تصدير التقارير (PDF/Excel)

## 🚀 التثبيت والتشغيل

### المتطلبات
- Python 3.7+
- Flask وإضافاته
- قاعدة بيانات البوت الأساسي

### التثبيت السريع

1. **تثبيت المكتبات المطلوبة:**
```bash
pip install -r dashboard/requirements.txt
```

2. **تشغيل لوحة التحكم:**
```bash
python3 start_dashboard.py
```

3. **الوصول للوحة:**
- افتح المتصفح وانتقل إلى: `http://localhost:5000`
- أو مباشرة لصفحة تسجيل الدخول: `http://localhost:5000/login`

### التشغيل اليدوي

```bash
cd dashboard/backend
python3 app.py
```

## 🔌 API Endpoints

### المصادقة
- `POST /api/auth/request-otp` - طلب رمز OTP
- `POST /api/auth/verify-otp` - تأكيد رمز OTP

### الإحصائيات
- `GET /api/dashboard/stats` - إحصائيات الصفحة الرئيسية
- `GET /api/analytics/growth` - إحصائيات نمو المستخدمين
- `GET /api/analytics/revenue` - إحصائيات الإيرادات

### إدارة المستخدمين
- `GET /api/users` - جلب قائمة المستخدمين
- `PUT /api/users/{id}` - تحديث بيانات مستخدم
- `GET /api/users/{id}/transactions` - معاملات المستخدم

### طلبات السحب
- `GET /api/withdrawals` - جلب طلبات السحب
- `PUT /api/withdrawals/{id}` - تحديث حالة طلب السحب

### الرسائل
- `POST /api/broadcast` - إرسال رسالة جماعية

### النظام
- `GET /api/system/health` - حالة النظام
- `GET /api/cards/inventory` - مخزون الكروت
- `POST /api/backup/create` - إنشاء نسخة احتياطية

## 📋 استكشاف الأخطاء

### مشاكل شائعة

**1. خطأ في قاعدة البيانات**
```
Error: Database file not found
```
**الحل**: تأكد من وجود ملف `yemen_net.db` في المجلد الصحيح

**2. خطأ في إرسال OTP**
```
Error: Failed to send OTP
```
**الحل**: تأكد من أن البوت يعمل وأن التوكن صحيح

**3. خطأ في تسجيل الدخول**
```
Error: Super admin access required
```
**الحل**: تأكد من أن حسابك له صلاحيات المشرف الأعلى في البوت
