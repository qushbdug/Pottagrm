# Yemen Net Bot v2 🚀

## نظرة عامة

**Yemen Net Bot v2** هو إصدار محسن ومطور بالكامل من بوت تليجرام الأصلي، مصمم لتوفير خدمات مالية متقدمة مع بنية برمجية قوية وأداء عالي.

## ✨ الميزات الجديدة

### 🔧 البنية المحسنة
- **معمارية معيارية**: فصل واضح بين المكونات المختلفة
- **إدارة أخطاء متقدمة**: معالجة محددة للأخطاء بدلاً من `except Exception`
- **نظام تسجيل محسن**: تسجيل شامل مع مستويات مختلفة
- **إدارة التكوين**: تكوين مرن عبر متغيرات البيئة

### 🚀 تحسينات الأداء
- **Connection Pooling**: إدارة محسنة لاتصالات قاعدة البيانات
- **نظام Cache متقدم**: TTL، LRU eviction، ومراقبة شاملة
- **Rate Limiting ذكي**: حماية من الإساءة مع قواعد قابلة للتخصيص
- **عمليات غير متزامنة**: دعم كامل لـ async/await

### 📊 المراقبة والتحليل
- **نظام مراقبة شامل**: جمع المقاييس والإحصائيات
- **فحوصات الصحة**: مراقبة حالة النظام والخدمات
- **نظام تنبيهات**: تنبيهات تلقائية للمشاكل
- **تقارير الأداء**: تحليل شامل لأداء البوت

### 🛡️ الأمان
- **إدارة الصلاحيات**: نظام صلاحيات متقدم للمستخدمين
- **حماية من الإساءة**: rate limiting متعدد المستويات
- **تشفير البيانات**: حماية البيانات الحساسة
- **سجلات التدقيق**: تتبع كامل للعمليات

## 🚀 التثبيت والتشغيل

### المتطلبات الأساسية
- Python 3.8+
- SQLite3
- Telegram Bot Token

### خطوات التثبيت

1. **استنساخ المشروع**
```bash
git clone <repository-url>
cd bot_v2
```

2. **إنشاء البيئة الافتراضية**
```bash
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# أو
venv\Scripts\activate     # Windows
```

3. **تثبيت المكتبات**
```bash
pip install -r requirements.txt
```

4. **إعداد متغيرات البيئة**
```bash
cp .env.example .env
# تعديل .env مع القيم الصحيحة
```

5. **تشغيل البوت**
```bash
python main.py
```

## ⚙️ التكوين

### متغيرات البيئة الأساسية

```env
# Bot Configuration
BOT_TOKEN=your_telegram_bot_token
BOT_NAME=Yemen Net Bot
BOT_USERNAME=yemen_net_bot

# Database Configuration
DB_PATH=yemen_net.db
DB_TIMEOUT=30
DB_MAX_CONNECTIONS=10

# Rate Limiting
RATE_LIMIT_REQUESTS=30
RATE_LIMIT_WINDOW=60

# Performance
CACHE_TTL=300
MAX_CONCURRENT_REQUESTS=100

# Monitoring
ENABLE_MONITORING=true
MONITORING_INTERVAL=60
```

## 🚨 استكشاف الأخطاء

### المشاكل الشائعة

1. **خطأ في قاعدة البيانات**
   - تأكد من وجود ملف قاعدة البيانات
   - تحقق من الصلاحيات
   - راجع سجلات الأخطاء

2. **مشاكل في الاتصال**
   - تحقق من صحة BOT_TOKEN
   - تأكد من اتصال الإنترنت
   - راجع إعدادات Firewall

3. **مشاكل في الأداء**
   - تحقق من استخدام الذاكرة
   - راجع إعدادات Cache
   - فحص قاعدة البيانات

### سجلات الأخطاء
