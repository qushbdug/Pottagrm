## 🚀 التثبيت والتشغيل

### **المتطلبات الأساسية**
```bash
# Python 3.8 أو أحدث
python --version

# Git
git --version
```

### **خطوات التثبيت**

#### 1. **استنساخ المشروع**
```bash
git clone https://github.com/your-username/yemen-net-bot.git
cd yemen-net-bot
```

#### 2. **إنشاء البيئة الافتراضية**
```bash
# إنشاء البيئة
python -m venv venv

# تفعيل البيئة
# على Linux/Mac:
source venv/bin/activate
# على Windows:
venv\Scripts\activate
```

#### 3. **تثبيت المتطلبات**
```bash
pip install -r requirements.txt
```

#### 4. **إعداد متغيرات البيئة**
```bash
# إنشاء ملف .env
cp .env.example .env

# تعديل الملف بالمعلومات المطلوبة
nano .env
```

**محتوى ملف .env:**
```env
# إعدادات البوت
BOT_TOKEN=your_bot_token_here
DB_PATH=./yemen_net.db

# إعدادات الأعمال
CARD_COMMISSION_RATE=0.10
AGENT_COMMISSION_RATE=0.05
MAX_TRANSFER_AMOUNT=10000.0
MIN_TRANSFER_AMOUNT=1.0

# إعدادات السجل
LOG_LEVEL=INFO
```

#### 5. **تشغيل البوت**
```bash
# تشغيل البوت
python src/bot.py

# أو استخدام main.py
python main.py
```
